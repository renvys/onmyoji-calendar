# 逢魔日历

阴阳师逢魔首领与“极”玩法词条轮换日历。

在线访问：https://renvys.github.io/onmyoji-calendar/

这是一个可直接部署到 GitHub Pages 的纯静态网页，无需安装依赖或执行构建命令。

## 功能

- 周一至周日自动匹配逢魔首领
- 周二至周五显示“极”玩法及对应轮换词条
- 根据轮换规则自动推算任意日期的词条
- 支持年份、月份快速选择
- 支持上个月、下个月、滚轮切换月份
- 支持选择日期和一键回到今天
- 星期标题显示首领名称和“极”标记
- 桌面端采用一屏布局，并显示完整每周首领安排
- 手机端隐藏每周首领安排，日历词条仅显示文字
- 页面显示累计访问次数

## 词条计算规则

词条轮换顺序：

斗魂 → 疾行 → 巧劲 → 易碎 → 咒术 → 猛火 → 狂风

每经过一周，四个“极”首领的词条均向后轮换一位。

首领、词条和计算配置集中在 `script.js` 顶部的 `CONFIG` 对象中。

## 页面适配

### 桌面端

- 详情、月历和每周首领安排尽量保持在一个视口内
- 日历显示词条名称及对应图标
- 访问次数显示在页面右下角

### 手机端

- 隐藏“每周首领安排”
- 日历中的词条仅显示文字，不显示图标
- 调整日期格和年月选择器尺寸，适配窄屏操作
- 访问次数显示在页脚

## 性能优化

- 无框架、无构建工具和运行时依赖
- 词条图标使用 WebP 雪碧图
- 运行时图标资源内嵌在 CSS 中，避免额外图片请求
- 移除高开销的图标滤镜和动画效果
- 访问统计在页面加载完成、浏览器空闲时异步加载
- 统计服务不可用时不会影响日历使用

图标源文件保留在 `assets/term-icons/` 目录中。

## 项目结构

- `index.html`：页面结构
- `script.js`：日历、首领和词条计算逻辑
- `styles.css`：主题及主要响应式样式
- `calendar-layout.css`：日历布局细节
- `mobile-grid.css`：手机端日期网格样式
- `assets/term-icons/`：词条图标源文件

## 本地预览

项目没有安装依赖，启动任意静态文件服务器即可：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/
```

## 部署到 GitHub Pages

1. 将仓库中的页面、样式、脚本和资源文件推送到 GitHub。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)` 目录后保存。
5. 等待 GitHub Pages 完成部署。

## 访问统计

页面使用不蒜子提供累计访问次数统计。

统计脚本在首屏加载完成后异步加载，不会阻塞日历渲染。由于统计依赖第三方服务，隐私保护扩展或网络限制可能导致访问次数不显示。
