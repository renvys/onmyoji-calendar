# 逢魔日历

可直接部署到 GitHub Pages 的纯静态网页，无需安装依赖或执行构建命令。

## 功能

- 周一至周日自动匹配逢魔首领
- 周二至周五显示“极”玩法及轮换词条
- 以 2026-07-27 至 2026-08-02 为基准周推算前后日期
- 年月快速选择（从 2022 年开始）、滚轮切换月份、日期选择、回到今天
- 年份和月份均使用自定义同主题下拉框
- 星期标题下显示完整首领名称与“极”标记，日期格重点展示轮换词条
- 桌面端采用一屏布局，无需向下滚动即可查看完整每周首领安排
- 桌面端与手机端响应式布局

## 词条计算规则

词条顺序：斗魂 → 疾行 → 巧劲 → 易碎 → 咒术 → 猛火 → 狂风。

基准周中：

- 周二（蜃气楼）：疾行
- 周三（土蜘蛛）：巧劲
- 周四（荒骷髅）：易碎
- 周五（地震鲶）：咒术

每经过一周，四个“极”首领的词条均向后轮换一位。配置集中在 `script.js` 顶部的 `CONFIG` 对象中。

## 部署到 GitHub Pages

1. 将 `index.html`、`styles.css`、`script.js` 上传到 GitHub 仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择对应分支和 `/ (root)` 后保存。
